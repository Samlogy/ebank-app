# Procédure — Bloquer et débloquer une carte bancaire

## Blocage immédiat (perte, vol, fraude)
1. Ouvrez **Cartes**, sélectionnez la carte concernée.
2. Appuyez sur **Bloquer la carte**. Le blocage est **instantané** : toute nouvelle
   opération est refusée.
3. Choisissez le motif : *perte*, *vol*, *fraude soupçonnée*, *blocage temporaire*.
4. Pour une perte ou un vol, demandez le **renouvellement** de la carte dans le même
   écran ; une nouvelle carte est expédiée sous 3 à 5 jours ouvrés.

## Blocage temporaire vs opposition définitive
- **Blocage temporaire** : réversible, utile si vous avez égaré votre carte chez vous.
  Vous pouvez la débloquer vous-même.
- **Opposition (perte/vol/fraude)** : définitive, la carte est annulée et remplacée.
  Elle ne peut pas être débloquée.

## Débloquer une carte
Uniquement possible si le blocage était **temporaire** :
1. Ouvrez **Cartes > carte bloquée temporairement**.
2. Appuyez sur **Débloquer**. Confirmez avec un code OTP.
3. La carte redevient utilisable immédiatement.

## En cas de débits frauduleux
Après avoir bloqué la carte, ouvrez un litige pour chaque opération non reconnue
(voir « Contester une transaction »). Le blocage seul n'annule pas les débits déjà
effectués.

## Cartes virtuelles
Les cartes virtuelles à usage unique se désactivent automatiquement après le premier
paiement ou à leur date d'expiration ; aucun blocage manuel n'est nécessaire.
