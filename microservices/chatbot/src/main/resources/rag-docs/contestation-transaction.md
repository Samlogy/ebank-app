# Procédure — Contester une transaction / signaler une fraude

## Quand contester ?
Contestez une transaction si vous constatez :
- un débit que vous ne reconnaissez pas ;
- un montant différent de celui autorisé ;
- un double débit pour un même achat ;
- un prélèvement après annulation d'un abonnement.

## Délais
- **Carte bancaire** : jusqu'à 13 mois après la date de débit (8 semaines pour un
  prélèvement SEPA autorisé, 13 mois pour un prélèvement non autorisé).
- Agissez le plus tôt possible : au-delà des délais légaux, le remboursement n'est
  plus garanti.

## Étapes
1. Ouvrez **Transactions**, sélectionnez l'opération concernée puis **Contester**.
2. Choisissez le motif : *fraude*, *erreur de montant*, *service non rendu*,
   *double débit*.
3. Joignez tout justificatif utile (facture, e-mail d'annulation, capture d'écran).
4. Validez. Un dossier de litige est créé avec un numéro de suivi.
5. Si la fraude concerne votre carte, **bloquez immédiatement la carte** (voir la
   procédure « Blocage de carte ») pour éviter d'autres débits.

## Ce qui se passe ensuite
- Un **remboursement provisoire** peut être crédité sous 1 à 3 jours ouvrés pour les
  fraudes avérées sur carte.
- L'enquête peut durer jusqu'à 30 à 90 jours selon le réseau (Visa/Mastercard).
- Vous êtes notifié de la décision par message sécurisé et e-mail.

## Bon à savoir
- Ne communiquez jamais votre code confidentiel ni un code OTP à un tiers, même se
  présentant comme un conseiller eBank : **eBank ne vous demandera jamais ces codes**.
- Une opposition pour fraude n'entraîne aucun frais.
