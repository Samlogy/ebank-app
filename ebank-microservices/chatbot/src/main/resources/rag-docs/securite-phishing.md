# Procédure — Sécurité du compte et lutte anti-phishing

## Règles d'or
- **eBank ne vous demandera JAMAIS** par téléphone, SMS ou e-mail : votre mot de passe,
  votre code confidentiel de carte, ou un code OTP.
- Ne cliquez pas sur les liens des SMS/e-mails non sollicités. Accédez toujours à eBank
  en tapant l'adresse vous-même ou via l'application officielle.
- Vérifiez le cadenas HTTPS et le domaine exact avant de saisir vos identifiants.

## Activer l'authentification forte (2FA / SCA)
1. Ouvrez **Profil > Sécurité**.
2. Activez la **validation par application** (recommandé) plutôt que le SMS.
3. Enregistrez un appareil de confiance.

## Que faire en cas de fraude suspectée ?
1. **Bloquez immédiatement** la carte concernée (voir « Blocage de carte »).
2. **Changez votre mot de passe** eBank depuis un appareil sûr.
3. **Contestez** les opérations non reconnues (voir « Contester une transaction »).
4. Signalez le message frauduleux via **Aide > Signaler un phishing**.

## Reconnaître un message frauduleux
- Sentiment d'urgence (« votre compte va être bloqué »).
- Fautes d'orthographe, adresse d'expéditeur douteuse.
- Demande de « confirmer » vos identifiants via un lien.
- Numéro de téléphone inconnu se faisant passer pour le service fraude.

## Bonnes pratiques
- Mot de passe unique et long, gestionnaire de mots de passe recommandé.
- Mises à jour de l'application activées.
- Notifications de paiement activées pour repérer toute opération anormale en temps réel.
